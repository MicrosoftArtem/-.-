Техническое задание: «Телефонная книга»
1. Назначение
Консольное приложение для управления списком контактов. Пользователь может добавлять, просматривать, искать и удалять контакты через текстовое меню.

2. Структура данных
Контакты хранятся в памяти в виде списка списков:

text
phonebook = [['Имя', 'Номер'], ...]
Каждый контакт — список из двух элементов: имя (строка) и номер телефона (строка).

3. Функциональные требования
3.1. Главное меню
При запуске приложение выводит меню из 5 пунктов:

№	Действие
1	Показать все контакты
2	Добавить контакт
3	Найти контакт
4	Удалить контакт
5	Выйти
После выполнения действия меню отображается заново. При вводе числа вне диапазона 1–5 выводится сообщение об ошибке.

3.2. Показать все контакты (пункт 1)
Если список пуст — выводится «Телефонная книга пуста.»
Если список не пуст — выводятся все контакты в формате:
text
Имя: <имя> | Телефон: <номер>
3.3. Добавить контакт (пункт 2)
Пользователь вводит имя и номер телефона.
Проверка дубликата: если контакт с таким именем уже существует (сравнение без учёта регистра), выводится сообщение об ошибке и контакт не добавляется.
Проверка пустого ввода: если имя или номер пустые или состоят только из пробелов — выводится сообщение об ошибке, контакт не добавляется.
При успешном добавлении выводится подтверждение.
3.4. Найти контакт (пункт 3)
Пользователь вводит имя для поиска.
Поиск выполняется без учёта регистра.
Если контакт найден — выводится строка:
text
Найдено -> Имя: <имя> | Телефон: <номер>
Если не найден — выводится сообщение об отсутствии контакта.
3.5. Удалить контакт (пункт 4)
Пользователь вводит имя контакта для удаления.
Поиск имени выполняется без учёта регистра.
Если контакт найден — удаляется из списка, выводится подтверждение.
Если не найден — выводится сообщение об отсутствии контакта.
Удаление должно использовать list.remove(contact), а не pop(i) при итерации по индексу.
3.6. Выход (пункт 5)
Выводится прощальное сообщение.
Программа завершает работу.
4. Нефункциональные требования
Язык интерфейса: русский.
Регистронезависимость: поиск, проверка дубликатов и удаление не зависят от регистра имени.
Очистка ввода: все пользовательские входы обрабатываются через .strip() для удаления лишних пробелов.
Обработка ввода: некорректные пункты меню не приводят к падению программы.
5. Ограничения текущей версии
Данные хранятся только в оперативной памяти — при выходе не сохраняются.
Нет редактирования существующего контакта.
Нет хранения нескольких номеров для одного имени.
Нет валидации формата номера телефона (допускается любая строка).
Поиск ведётся только по точному совпадению имени, без частичного совпадения.
6. Возможные доработки (на будущее)
Сохранение и загрузка контактов из файла (CSV или JSON).
Редактирование контакта.
Поиск по части имени или по номеру телефона.
Валидация номера телефона (только цифры, формат 8XXXXXXXXXX).
Хранение нескольких номеров для одного контакта.
Сортировка контактов по имени.
